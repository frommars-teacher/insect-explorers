# 곤충탐험대

학생들을 위한 곤충 400종 랜덤 탐험 웹앱입니다. 설치나 로그인 없이 웹브라우저에서 사용할 수 있습니다.

## 기능

- 곤충 사진·이름·학명·발견 노트를 랜덤으로 뽑기
- 분류별 탐험과 미발견 곤충만 뽑기
- 발견 도감, 즐겨찾기, 이름·학명 검색
- 브라우저에 발견 기록 저장

일부 해외종은 영문명 또는 학명으로 표시됩니다. 기록은 기기와 브라우저별로 저장됩니다.

## GitHub Pages

저장소 Settings → Pages → Deploy from a branch → main / (root) → Save를 선택합니다. 빌드 도구와 API 키는 필요하지 않습니다.

## 사진과 생물 정보

사진과 생물 분류 자료는 iNaturalist 공개 자료를 사용했습니다. 각 사진의 촬영자, 원본 링크, Creative Commons 라이선스는 `insects.json` 및 웹앱의 개별 카드에 표시됩니다. 일부 사진에는 비영리 또는 동일조건변경허락 조건이 있으므로 재사용 시 개별 라이선스를 확인해 주세요. 종별 이야기의 출처도 개별 카드에 표시됩니다.

곤충 사진은 외부 서버에서 불러오므로 인터넷 연결이 필요합니다.
